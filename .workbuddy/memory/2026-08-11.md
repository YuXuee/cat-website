## 第四版：彻底改用原站真实 Divi CSS（pixel-perfect）

- 用户强调"我要你改成和那个网站的home页一模一样，好好解析一下"——之前手写近似 CSS 不够精确
- **关键发现**：原站样式由三部分组成，且原站已更新：
  1. 170KB inline `<style>`（Divi 基础样式，含 #top-header/#main-header/各模块规则 + ETmodules 字体 @font-face）
  2. `et-divi-dynamic-15.css`（页面专属：列背景粉色渐变 et_pb_column_1/3/6/7 等）
  3. `et-core-unified-deferred-15.min.css`（核心，较小）
- **做法**：直接采用原站真实 CSS，不再手写近似
  - 从 live 站提取全部 inline `<style>` → `css/divi.css`（169KB）
  - 下载动态 CSS → `css/divi-dynamic.css`，核心 CSS → `css/divi-core.css`
  - 从 live 站提取 HTML body 结构（#page-container→#top-header+#main-header+#et-main-area+#main-footer），保留全部 class 1:1
  - body class 原样保留（et_fixed_nav et_show_nav et_secondary_nav_enabled et_header_style_left et_pb_gutters3 等，驱动 CSS）
  - 三处修改：logo→文本"BY COCO"、导航只留 Home、可见文字 Kelly→Coco（图片URL/Instagram/Google Maps链接中的 Kelly 保留，否则图片裂图）
  - `css/custom.css` 仅用于文本 logo 样式 + 隐藏搜索图标 + sticky header
- 旧 `css/style.css` 已弃用（手写近似版），保留但不再引用
- 这样渲染必然与原站 home 页一致（同一套 CSS + 同一套 class 结构）
- 已重新部署到云端（同一链接），本地 localhost:3000 也可预览

## 第六版：修复顶部电话图标不显示 + 改回原站电话号码

- 问题：顶部栏 `#et-info-phone:before` 的电话图标使用 ETmodules 字体图标（`content: "\e090"`），但 divi.css 中 @font-face 指向原站 `//ragdollkittensbykelly.com/...` 字体文件，跨域 CORS 导致字体无法加载，图标不显示
- 解决：
  - 下载 ETmodules 字体文件到本地 `fonts/` 目录（etmodules.eot / .woff / .ttf）
  - 修改 `css/divi.css` 中 @font-face 的 src URL 指向本地字体
  - 本地服务器增加 `.woff`/`.ttf`/`.eot` 的 MIME 类型
- 同步把顶部电话号码从 `(626) 863-4435` 改回原站的 `(951) 534-1115`
